# урсовой проект по дисциплине «инансовая математика»

## Техническое задание и структура проекта:
1. Теоретическое определение финансовой математики как науки.
2. ывод и описание математических формул наращения и дисконтирования капитала по простым процентным ставкам.
3. ывод и описание математических формул наращения и дисконтирования капитала по сложным процентным ставкам.
4. Сравнительное описание 3 мировых практик начисления процентов (стандарты ACT/ACT, ACT/360, 30/360).
5. 12 практических вариантов задач с разбором и вычислениями денежных средств (до 2 знаков после запятой).
6. лгоритм на языке JavaScript для построения таблицы «орядковые номера дней в году» для невисокосного года.
7. рограмма на языке JavaScript для расчета параметров долговых обязательств (6 вариантов пересечения практик и типов процентных ставок) на сроки от 30 дней до 10 лет.
8. азгрузочные интерактивные слайды с графическим сопровождением по теме сложных процентов.
